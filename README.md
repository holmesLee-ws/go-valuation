# go-valuation

기업·지분 가치평가를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 국내 법령·기준(상속세 및 증여세법의 비상장주식 평가, 자본시장법의 합병가액과 외부평가, K-IFRS 공정가치 측정, 한국공인회계사회 가치평가서비스 수행기준 등)을 뼈대로, 국제평가기준(IVS)과 미국 실무를 비교 축으로 배웁니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도, 법령·기준의 출처 원장, 튜터의 행동 규칙만 있습니다. 도식과 계산, 조사 자료를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

이 워크스페이스는 학습 도구이고 세무·회계·법률 자문이 아닙니다. 실제 거래에 적용할 때는 전문가의 확인을 받으세요.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다. 계산은 평소 쓰는 엑셀·구글 시트·계산기로 합니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-valuation
```

**Claude Code**

```bash
cd ~/Desktop/go-valuation
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 법령·자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-valuation` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 업무에서 평가·투자·합병·증여를 다뤄 봤는지 짧게 묻고, 영역마다 문제를 하나씩 풀어 출발점을 찾습니다. 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML(도식·계산)을 만들어 가며 익힙니다. 내 업무 상황을 예시로 씁니다.
4. 법령·기준 조문은 튜터가 기억으로 말하지 않고 출처 원장이나 공식 사이트에서 확인한 날짜와 함께 말합니다.
5. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
6. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.
7. 마지막에는 실제 업무 산출물(비상장 지분 가치평가 보고서 초안, 외부평가 보고서 검토 의견서)을 만듭니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(기초 F, 방법론 M, 목적별 제도 R, 실무 P, 졸업 X) |
| [curriculum/sources.md](curriculum/sources.md) | 법령·기준 출처 원장(공식 URL·조회일) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 계산 자료. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼과 원장을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 계산 자료를 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 회사명·개인 정보 같은 민감한 정보는 대화에 넣지 마세요.
